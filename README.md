# 삼각팡 (TrigPang) 🍍

수열팡 시리즈 2탄 — **값이 같으면 생김새가 달라도 이어진다.**

시리즈 1탄 [시퀀스팡(수열팡)](https://github.com/CauchyRiemannEquations/sequencepang)의 디자인 언어를 그대로 이어받았다. 딥 포레스트 그린 배경, 아이보리 타일, 기울어진 타일 로고, 떠다니는 과일 파티클 — 다만 메인 과일은 멜론 🍈 대신 **파인애플 🍍**, 포인트 컬러는 라임 대신 **파인애플 골드**.

sin 30°, cos 60°, sin 5π/6, 1/2 는 전부 같은 값이고, 전부 한 사슬이다. 같은 값의 타일을 3개 이상 드래그로 이어 터뜨리는 삼각함수 팡 게임.

## 플레이

- 6×6 보드에서 인접한 타일을 드래그로 연결하고 손을 떼면 팡
- 값이 같아야 이어진다 — 표기는 달라도 된다 (육십분법 · 호도법 · 숫자)
- 제한 시간 안에 목표 점수에 도달하면 라운드 클리어, 남은 시간은 보너스 점수
- 팡마다 단위원 동경이 해당 각도로 회전하며 `sin 150° = 1/2` 캡션 표시
- 단위원 게이지를 채우면 피버 — 8초간 점수 2배 (보드가 황금빛으로 변신)
- 최고 기록은 브라우저에 저장되어 메인 화면에 표시

## 난이도 구성 (현재 빌드)

메인 화면에서 난이도를 고르면 해당 범위로 무한 라운드가 진행된다. 라운드가 오를수록 목표 점수만 상승 (쉬움 ×1.3, 보통 ×1.35, 어려움·고수 ×1.4). 난이도별 최고 기록이 따로 저장된다.

| 난이도 | 범위 | 시작 목표 | 시간 |
|---|---|---|---|
| 쉬움 | 1사분면 · 육십분법 | 500 | 40초 |
| 보통 | 둔각까지 · 호도법 | 900 | 45초 |
| 어려움 | 전 범위 (0°–330°) 일반각 | 1,300 | 45초 |
| 고수 | 전 범위 + tan | 1,500 | 45초 |

값 체계는 sin·cos 특수각 기준 9클래스(0, ±1/2, ±√2/2, ±√3/2, ±1)에 고수 난이도에서 tan 4클래스(±√3/3, ±√3)가 추가된다. tan 45° = 1 = sin 90° 처럼 함수를 넘나드는 사슬도 가능. tan 90°·270°는 정의되지 않으므로 등장하지 않는다.

## 로드맵

- [x] 특수각 모드: 라운드제 → 난이도 선택제 개편 (쉬움 / 보통 / 어려움)
- [x] tan 포함 고급 난이도 (고수)
- [ ] 일반각 모드: 4방향 스와이프 분류 — sin(π−x) 같은 식을 sin x / −sin x / cos x / −cos x 로 축약, 오답 시 단위원 리플레이
