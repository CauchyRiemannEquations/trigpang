# 삼각팡 (TrigPang) 🍍

**값이 같으면 생김새가 달라도 이어진다.**

[시퀀스팡(수열팡)](https://github.com/CauchyRiemannEquations/sequencepang)의 디자인 언어를 이어받았다. 딥 포레스트 그린 배경, 아이보리 타일, 기울어진 타일 로고, 떠다니는 과일 파티클 — 다만 메인 과일은 멜론 🍈 대신 **파인애플 🍍**, 포인트 컬러는 라임 대신 **파인애플 골드**.

sin 30°, cos 60°, sin 5π/6, 1/2 는 전부 같은 값이고, 전부 한 사슬이다. 같은 값의 타일을 3개 이상 드래그로 이어 터뜨리는 삼각함수 팡 게임.

## 플레이

- 6×6 보드에서 인접한 타일을 드래그로 연결하고 손을 떼면 팡
- 값이 같아야 이어진다 — 표기는 달라도 된다 (육십분법 · 호도법 · 숫자)
- 제한 시간 안에 목표 점수에 도달하면 라운드 클리어, 남은 시간은 보너스 점수
- 팡마다 단위원 동경이 해당 각도로 회전하며 `sin 150° = 1/2` 캡션 표시
- 단위원 게이지를 채우면 피버 — 8초간 점수 2배 (보드가 황금빛으로 변신)
- 최고 기록은 브라우저에 저장되어 메인 화면에 표시

## 난이도 구성 (현재 빌드)

메인 화면에서 난이도를 고르면 해당 범위로 무한 라운드가 진행된다. 라운드가 오를수록 목표 점수만 상승 (쉬움 ×1.3, 보통 ×1.35, 어려움·고수 ×1.4). 난이도별 최고 기록이 따로 저장된다.

| 난이도 | 범위 | 시작 목표 | 시간 |
|---|---|---|---|
| 쉬움 | 1사분면 · 육십분법 | 500 | 40초 |
| 보통 | 둔각까지 · 호도법 | 900 | 45초 |
| 어려움 | 전 범위 (0°–330°) 일반각 | 1,300 | 45초 |
| 고수 | 전 범위 + tan | 1,500 | 45초 |
| 지옥 | 전 범위 + tan + csc · sec · cot | 1,800 | 45초 |

값 체계는 sin·cos 특수각 기준 9클래스(0, ±1/2, ±√2/2, ±√3/2, ±1)에 고수에서 tan 4클래스(±√3/3, ±√3), 지옥에서 역수함수 6클래스(±2, ±√2, ±2√3/3)가 추가된다. tan 45° = 1 = sin 90° = csc 90° 처럼 함수를 넘나드는 사슬도 가능. 정의되지 않는 각(tan 90° 등)은 등장하지 않는다.

## 일반각 모드 (스와이프)

sin(π−x), cos(3π/2+x) 같은 일반각 식이 카드로 나오면 **sin x / −sin x / cos x / −cos x** 중 하나로 축약해 4방향 스와이프(또는 버튼·방향키)로 분류한다.

- 위 = sin x · 아래 = −sin x · 왼쪽 = cos x · 오른쪽 = −cos x
- 60초 제한, 정답 +100점에 연속 정답 보너스(+20씩, 최대 +200)
- **오답 시 단위원 리플레이**: x = 30° 예시로 동경이 변환각으로 회전하며 왜 그 답인지 보여준다 (리플레이 중 타이머 정지)
- 변환 7종: −x, π±x, π/2±x, 3π/2±x

## 로드맵

- [x] 특수각 모드: 라운드제 → 난이도 선택제 개편 (쉬움 / 보통 / 어려움)
- [x] tan 포함 고급 난이도 (고수)
- [x] csc · sec · cot 지옥 난이도
- [x] 일반각 모드: 4방향 스와이프 분류 — sin(π−x) 같은 식을 sin x / −sin x / cos x / −cos x 로 축약, 오답 시 단위원 리플레이
- [ ] 랭킹 시스템 (수열팡 서버 연동)

## 메인 화면

- **특수각 팡!** 버튼을 누르면 난이도 5종이 가로 스크롤 카드로 펼쳐진다
- **일반각 팡!** 버튼으로 스와이프 모드 바로 진입
- 하단에 플레이 방법 · 업데이트 내역 · Contact
- 홈 화면에 설치 가능한 PWA — 안드로이드·iOS 모두 파인애플 아이콘

## 프로젝트 구조

시퀀스팡과 동일한 Vite + 바닐라 JS 모듈 구조.

```text
client/
  public/
    manifest.webmanifest      PWA 매니페스트
    service-worker.js         오프라인 캐시
    icon-192/512.png          파인애플 아이콘 (maskable · apple-touch 포함)
  src/
    main.js                   엔트리 · 모드 선택 와이어링
    gameConstants.js          값 테이블 · 난이도 · 일반각 변환
    pangGame.js               특수각 팡 (보드 엔진)
    swipeMode.js              일반각 팡 (스와이프)
    howToPlay.js              플레이 방법 모달
    updateNotes.js            업데이트 내역 모달
    ui.js                     화면 전환 · 공용 모달
    style.css
  index.html
vite.config.js
vercel.json
```

## 실행

```bash
npm install
npm run dev     # 개발 서버
npm run build   # client/dist 프로덕션 빌드
```

- Vercel: main 푸시 시 자동 배포 → https://trigpang.vercel.app
- GitHub Pages: Actions 워크플로가 빌드·배포 → https://cauchyriemannequations.github.io/trigpang/

## 기술

Vite + 바닐라 JS ES 모듈. 프레임워크 없음. 외부 의존성은 Google Fonts뿐.
